# ZGW Test Bench

Test bench for the Z/IP Gateway (ZGW): harness scripts and runners that
exercise the ZGW against a test bed with actual radio devices.

Start here:

- [AGENTS.md](AGENTS.md) -- shared operating context (hardware,
  scripts, conventions, quality gates).
- [endurance_test/README.md](endurance_test/README.md) -- walkthrough for
  running the endurance test.

The current focus is the endurance test. Future phases add functional tests
and automation evaluation. See `AGENTS.md` for the phase summary.
